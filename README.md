# TKC Hotel UX/UI

เปิด wed.html ใน VS Code แล้วกด Open in Integrated Browser หรือ Go Live

- wed.html: โครงสร้างหน้าเว็บ
- style.css: ธีมและ responsive layout
- script.js: ตัวกรองห้อง วันที่ สรุปราคา และแชตตัวอย่าง

รูปภาพและฟอนต์โหลดจากออนไลน์ ต้องมีอินเทอร์เน็ต

แก้ข้อมูลห้องได้ในตัวแปร rooms ของ script.js
